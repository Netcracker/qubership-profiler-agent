Load `english-developer-style` before writing or rewording any English text a developer will read: a code comment or
doc comment, a commit message, a pull request title or description, a changelog entry, a documentation page, an error or
log message, a UI string, a localization file. A task that ends in a commit ("fix the bug", "add the feature", "write
tests") also ends in comments, a commit message, and a description: load the skill before the first comment is written,
not when the description is due. Where an authoring skill for the artifact is installed (`javadoc-authoring`,
`godoc-authoring`, `rustdoc-authoring`, `jsdoc-authoring`, `pythondoc-authoring`, `change-description-authoring`,
`docs-page-authoring`), load it as well.
